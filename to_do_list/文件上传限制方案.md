# 文件上传限制方案：压缩包无限制 + 其他文件 500MB

## 一、问题背景

当前 `config.py` 中 `MAX_CONTENT_LENGTH` 对所有请求体生效，无法区分压缩包和其他文件类型。需求是：

- **压缩包**（`.zip`、`.rar`、`.7z`、`.tar`、`.gz`、`.bz2`、`.xz` 等）：**不限制上传大小**
- **其他文件**：限制 **500MB**

## 二、核心难点

Flask 的 `MAX_CONTENT_LENGTH` 是全局中间件级别限制，在请求到达路由处理函数**之前**就会被拦截，它无法区分文件类型。因此不能直接用 `MAX_CONTENT_LENGTH` 实现分类限制。

## 三、解决思路

### 整体流程

```
用户请求 → 通过Flask（移除全局大小限制）→ 路由处理函数 → 读取文件扩展名 → 分支判断
                                                                          ├── 压缩包 → 不限制大小
                                                                          └── 其他文件 → 限制 500MB
```

### 具体步骤

1. **修改 `config.py`** — 移除或大幅提高 `MAX_CONTENT_LENGTH`，让所有文件都能通过 Flask 全局检查
2. **在文件上传路由中添加自定义校验** — 根据文件扩展名判断类型，分别处理
3. **确保大文件上传使用流式写入** — 避免将大文件全部加载到内存导致 OOM

## 四、代码修改示例

### 4.1 修改 `config.py`

```python
# 移除全局限制，改由上传路由自行校验
# MAX_CONTENT_LENGTH = 500 * 1024 * 1024  # 删除此行或设为 None
MAX_CONTENT_LENGTH = None  # 关闭全局限制
```

### 4.2 新增 `app.py` 上传路由（示例）

```python
import os
from flask import Flask, render_template, request, jsonify
from models import db

# ============================================================
# 文件上传大小限制：压缩包无限制，其他文件 500MB
# ============================================================

# 压缩包扩展名集合
ARCHIVE_EXTENSIONS = {'.zip', '.rar', '.7z', '.tar', '.gz', '.bz2', '.xz', '.tgz', '.tar.gz', '.tar.bz2'}

MAX_FILE_SIZE = 500 * 1024 * 1024  # 500MB，非压缩包上限


def get_file_extension(filename):
    """获取文件扩展名（支持 .tar.gz 等复合扩展名）"""
    basename = os.path.basename(filename).lower()
    # 先检查复合扩展名
    for ext in ['.tar.gz', '.tar.bz2', '.tar.xz']:
        if basename.endswith(ext):
            return ext
    # 再检查单扩展名
    _, ext = os.path.splitext(basename)
    return ext


def is_archive(filename):
    """判断文件是否为压缩包"""
    return get_file_extension(filename) in ARCHIVE_EXTENSIONS


def validate_upload_size(uploaded_file):
    """
    校验上传文件大小
    返回: (is_valid, error_message)
    """
    filename = uploaded_file.filename

    if is_archive(filename):
        # 压缩包不限制大小
        return True, None
    else:
        # 非压缩包限制 500MB
        # 注意：Flask request.content_length 在请求进入时已知
        content_length = request.content_length
        if content_length and content_length > MAX_FILE_SIZE:
            size_mb = content_length / (1024 * 1024)
            return False, f'文件大小 {size_mb:.1f}MB 超过上限 500MB'
        return True, None


# 注册上传路由（示例，放在 register_routes 中）
def register_routes(app):

    @app.route('/')
    def index():
        return render_template('index.html')

    @app.route('/upload', methods=['POST'])
    def upload_file():
        if 'file' not in request.files:
            return jsonify({'error': '未选择文件'}), 400

        file = request.files['file']
        if file.filename == '':
            return jsonify({'error': '文件名为空'}), 400

        # 自定义大小校验
        is_valid, error_msg = validate_upload_size(file)
        if not is_valid:
            return jsonify({'error': error_msg}), 413

        # TODO: 文件保存逻辑
        # 建议使用流式写入，避免大文件全部读入内存
        # file.save(os.path.join(upload_path, filename))
        # 或使用 file.stream.read(chunk_size) 分块写入

        return jsonify({'message': '上传成功', 'filename': file.filename}), 200
```

## 五、注意事项

| 关注点 | 说明 |
|--------|------|
| **大文件内存** | 建议使用 `file.stream.read(chunk_size)` 分块写入磁盘，避免将整个文件加载到内存 |
| **nginx 反向代理** | 如果前端有 nginx，也需要配置 `client_max_body_size 0;` 移除 nginx 层的限制 |
| **超时设置** | 大文件上传耗时长，需调高 nginx/Gunicorn 的超时时间 |
| **扩展名绕过** | 攻击者可能伪造扩展名。可进一步结合 MIME 类型（magic bytes）校验 |
| **断点续传** | 超大压缩包建议后续实现分片上传 + 断点续传机制 |
